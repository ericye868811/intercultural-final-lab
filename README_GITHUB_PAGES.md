# Intercultural Final Lab — GitHub Pages

This folder is ready to publish as a static GitHub Pages site.

## Recommended repository
Create a new **public** GitHub repository, for example:

`intercultural-final-lab`

Then upload the entire contents of this folder to the repository root.

## Enable GitHub Pages
In GitHub:
1. Open the repository.
2. Settings → Pages.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Branch: `main`
5. Folder: `/ (root)`
6. Save.

The public address will normally be:

`https://<your-github-username>.github.io/intercultural-final-lab/`

## PWA / mobile
All manifest, service-worker and icon paths are relative, so this project also works when GitHub Pages publishes it under a repository subpath.

## Data/privacy
Learning progress remains in each visitor's browser localStorage. No account or backend is required.
